1. 🔹 Introduction to Pandas
•	What is Pandas? 
•	Why use Pandas over NumPy 
•	Key features: 
o	Handles tabular data 
o	Built on NumPy 
•	Installation:
pip install pandas
•	Import:
import pandas as pd
________________________________________
2. 🔹 Core Data Structures (VERY IMPORTANT ⭐)
📌 Series (1D)

•	Index + values 
•	Custom index:
pd.Series([10,20], index=['a','b'])
________________________________________
📌 DataFrame (2D)

    "name": ["A", "B"],
    "age": [20, 25]
})
•	Rows & columns 
•	Think of it like Excel table 
________________________________________
3. 🔹 Creating DataFrames
•	From dictionary 
•	From lists 
•	From NumPy arrays 
•	From CSV/Excel:
pd.read_csv("file.csv")
pd.read_excel("file.xlsx")
________________________________________
4. 🔹 Exploring Data
•	Basic functions:
df.head()
df.tail()
df.info()
df.describe()
df.shape
df.columns
________________________________________
5. 🔹 Indexing & Selection (VERY IMPORTANT ⭐)
This is one of the most tested topics.
Column selection:
df["age"]
df[["age", "name"]]
Row selection:
df.loc[0]
df.iloc[0]
Filtering:
df[df["age"] > 20]
________________________________________
6. 🔹 Data Cleaning
•	Handling missing values:
df.isnull()
df.dropna()
df.fillna()
•	Removing duplicates:

________________________________________
7. 🔹 Data Manipulation

o	sum(), mean(), count()
